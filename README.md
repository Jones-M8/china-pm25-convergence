# china-pm25-convergence
UN5550 Global Health project PM2.5 trends and cross-border pollution disparities across China, Japan, South Korea, and India (2010–2023) using WHO data 


# Repository Structure
- 'data/' — Contains the uncleaned WHO PM2.5 records alongside the processed four-nation study dataset.
- 'notebooks/pm25_analysis.ipynb' — The primary analytical script incorporating data cleaning, exploratory evaluations, graphical figures, and baseline statistical testing.
- 'docs/' — Supplementary project files and contextual information.
- 'README.md' — Overview of the project scope and directory contents.

# Running the Notebook
1. Obtain a copy of this repository via cloning or direct download.
2. Launch notebooks/pm25_analysis.ipynb within Jupyter Notebook, JupyterLab, VS Code, or an equivalent computational platform.
3. Ensure the requisite Python dependencies are installed: pandas, NumPy, Matplotlib, Seaborn, and SciPy.
4. Execute all code cells sequentially from top to bottom.

The notebook uses the data files stored in the repository's data/ directory.
